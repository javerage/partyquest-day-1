## Activation Contract
Use before proposing or implementing a PartyQuest change tied to a roadmap increment.

## Hard Rules
- Read the student `AGENTS.md`, selected roadmap row, prerequisites, and linked public contract first.
- Do not implement before the student explicitly authorizes that exact increment.
- Do not change another increment, roadmap status, or unrelated files.

## Decision Gates
- If the ID, acceptance evidence, or edit scope is unclear, stop and ask a closed, specific question.
- If a prerequisite lacks evidence, report it; do not assume completion.

## Steps
1. State the observable result, criteria, candidate paths, and checks before editing.
2. After authorization, implement only the selected increment; preserve unrelated work.
3. Report files, exact commands, observed results, and remaining proof; stop before the next increment.

## Output
Give a concise proposal before work and an evidence-based handoff afterward. Never mark progress complete for the student.
