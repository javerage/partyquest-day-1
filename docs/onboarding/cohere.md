# Preparar tu cuenta de Cohere — Día 1

**Objetivo de hoy:** dejar lista la cuenta personal para el trabajo de embeddings del Día 2. No instalar el SDK, generar embeddings ni construir un índice en D1.

## Pasos

1. Abre el [registro oficial de Cohere](https://dashboard.cohere.com/welcome/register) y comprueba el dominio.
2. Si ya tienes cuenta, usa la opción de inicio de sesión. Si no, completa el registro con el método que el sitio ofrezca.
3. Atiende la verificación de correo u otros requisitos si aparecen. No compartas códigos, contraseña ni datos de facturación.
4. Confirma que puedes entrar a tu panel personal.
5. Localiza la sección [API Keys](https://dashboard.cohere.com/api-keys), sin crear ni copiar una clave para la preparación D1.
6. Revisa las condiciones que muestre tu propia cuenta. Aunque la documentación menciona claves de prueba, no se garantiza acceso, cuota ni uso gratuito para todos los participantes.
7. Registra «acceso al panel comprobado» o el bloqueo encontrado, sin información privada.

## Detente aquí

La clave y el SDK se configuran al autorizar el incremento correspondiente de D2. No agregues credenciales de Cohere a PartyQuest D1, no las pegues en un chat y no conectes recursos de otra persona.

Si el sitio exige pago o verificación adicional que no esperabas, consulta al facilitador. No eludas requisitos ni uses una cuenta compartida como solución automática.
