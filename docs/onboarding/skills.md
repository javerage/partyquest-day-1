# Skills del proyecto

Estas skills son material original del taller, escrito para los incrementos D1 y guardado dentro del proyecto. OpenCode descubre `.opencode/skills/<id>/SKILL.md`; no se requiere instalador, configuración global ni cambio de registro. En un prompt puedes invocar `@<id>` explícitamente. [Gentle AI](gentle-ai.md) agrega sus propias skills generales; las cuatro del taller siguen disponibles y las fichas las invocan por su nombre. Referencia de formato y descubrimiento: [documentación oficial de OpenCode](https://opencode.ai/docs/skills/).

| ID | Ruta exacta | Activación / uso |
|---|---|---|
| `increment-scope` | `.opencode/skills/increment-scope/SKILL.md` | Proponer y limitar un incremento del roadmap antes de editar. |
| `contract-testing` | `.opencode/skills/contract-testing/SKILL.md` | Crear pruebas deterministas a partir del contrato público. |
| `debugging` | `.opencode/skills/debugging/SKILL.md` | Aislar fallos sin ampliar alcance ni exponer secretos. |
| `verification` | `.opencode/skills/verification/SKILL.md` | Relacionar checks observados con criterios y evidencia pendiente. |

Los IDs corresponden a los nombres de carpeta; los archivos incluyen descripciones de activación. El material fue creado para este curso. No se copió contenido de skills de terceros y no se afirma una licencia de terceros para estas skills.
