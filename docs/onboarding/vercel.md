# Preparar tu cuenta de Vercel — Día 1

**Objetivo de hoy:** entrar al panel de tu cuenta personal. La publicación de PartyQuest corresponde a una etapa posterior y requiere autorización explícita para ese proyecto y esa operación.

## Pasos

1. Abre el [registro oficial de Vercel](https://vercel.com/signup) y comprueba el dominio.
2. Si tienes cuenta, inicia sesión. Si no, selecciona uno de los métodos de registro disponibles y completa el flujo.
3. Si eliges una cuenta de Git como método de acceso, revisa los permisos solicitados. Autenticarte no es una instrucción para importar todos tus repositorios o conectar una organización del trabajo.
4. Completa la verificación que pida el sitio sin compartir contraseñas, códigos ni datos personales con el agente.
5. Confirma acceso a tu panel y revisa la cuenta/equipo activo. No presupongas que estás en una cuenta personal si también tienes una cuenta laboral.
6. Detente antes de **importar un repositorio**, **crear un proyecto**, **conectar integraciones**, **desplegar** o **agregar pagos**.
7. Registra únicamente «acceso al panel comprobado» o un bloqueo no sensible.

## Lo que no hacemos en esta preparación

No hace falta instalar Vercel CLI, un plugin ni un servidor MCP para crear la cuenta. Tampoco ejecutar `vercel`, iniciar un deploy temporal ni conceder al agente permisos sobre la cuenta. La documentación oficial incluye recorridos más amplios: no copies su prompt de instalación y despliegue como una orden para este bloque.

Si el servicio exige un plan de pago o un permiso no previsto, consulta al facilitador antes de aceptarlo. No se garantiza acceso gratuito ni límites específicos.

## Checklist

- [ ] Entré al panel de la cuenta que usaré personalmente en el taller.
- [ ] Identifiqué la cuenta/equipo activo.
- [ ] No importé repositorios, creé proyectos ni desplegué.
- [ ] No instalé CLI/MCP/plugins ni compartí credenciales.
