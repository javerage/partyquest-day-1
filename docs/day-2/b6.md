# Día 2 · Bloque 6 — Preparar la publicación (sin desplegar)

## Objetivo

Prepara la misma aplicación D2 para una futura publicación del estudiante. D2 no publica, conecta cuentas ni crea recursos; publicación y comprobación en cuenta personal son trabajo D3, con autorización explícita para destino y operación. No se hacen afirmaciones de runtime desplegado, ni se distribuyen claves o solución docente.

Conserva frontend y API separados; solo la API se comunica con proveedores. Mantén `POST /api/chat` y los comandos locales documentados en [README](../../README.md): `npm run dev:api`, `npm run dev:frontend`, `npm test`, `npm run typecheck` y `npm run build` (PowerShell usa `npm.cmd`). Estos comandos no despliegan. La entrada incluye `api/data/places.json` y `api/data/corpus/lugares-valladolid.md`. El índice se construye en B3; no se entrega al empezar. En B6 prepara el punto de entrada de la función y `vercel.json`, y comprueba que el empaquetado conserva los tres recursos. Catálogo/corpus/índice deben ser artefactos preconstruidos disponibles a la API, nunca reconstruidos al arrancar/publicar. `GROQ_API_KEY` y `COHERE_API_KEY` son secretos server-side, nunca en frontend, bundle, logs, commits ni documentación. Diferencia valores no secretos y locales; no inventes configuración ni afirmes validación de plataforma.

## Incrementos y prompts

I1 inventario/configuración; I2 runtime/enrutamiento; I3 datos de ejecución; I4 traspaso a D3. Antes de uno, propuesta sin cambios con rutas exactas, criterios B6, fuente oficial a consultar y verificaciones. Autoriza explícitamente uno. Prepara pruebas en cada incremento, pero por decisión del taller ejecútalas al cierre del ejercicio completo. CLI es opcional, no dependencia de PartyQuest; no instales ni conectes cuentas sin autorización específica. Una construcción local no es despliegue. No uses `vercel build`, `vercel pull`, `vercel link` ni comandos de despliegue en este ejercicio: pueden usar/descargar configuración o credenciales y no forman parte de esta verificación local.

**Prompt 1 — propuesta:**
> Quiero trabajar solo en [I1–I4] de B6. Primero propone sin editar rutas exactas, criterio B6, riesgos de secretos/datos y comprobaciones a preparar para el cierre del ejercicio. No conectes cuentas, ejecutes operaciones remotas, instales herramientas, publiques ni hagas commits. Espera autorización explícita.

**Prompt 2 — ejecución autorizada:**
> Autorizo exclusivamente [incremento y rutas acordados]. Implementa solo ese alcance y prepara las pruebas; no las ejecutes hasta el cierre completo. No conectes cuenta, descargues configuración/credenciales, publiques ni avances. Informa qué quedó preparado/implementado y qué falta verificar.
