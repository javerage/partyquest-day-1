Zero-shot y few-shot: con o sin ejemplos

zero-shot · instrucción sin ejemplos
system  Responde en una sola frase,
        con tono cercano.

user    Quiero salir el sábado
few-shot · instrucción con ejemplos
system  Responde en una sola frase,
        con tono cercano.
        Ejemplo: «Tengo hambre» →
        «¡Vamos por algo rico!»

user    Quiero salir el sábado

Los ejemplos orientan formato o estilo. El mensaje de usuario se mantiene constante para poder comparar.
