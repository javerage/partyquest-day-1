PartyQuest · Interfaz D1

Referencia visual estática de los estados del chat y la composición por componentes. Derivada del diseño aprobado; no representa una implementación funcional.

Alcance: D1 crea una sola interfaz de chat con estados, no páginas separadas. Los textos y lugares de muestra son ilustrativos. La fuente normativa son el mapa de pantallas/componentes, el sistema de diseño aprobado (documentado en el repositorio) y el contrato D1.

Componentes que forman la vista

Responsabilidades de presentación; el estado real y la coordinación se construyen en el slice `chat`.

TopBar

Acciones «Nuevo plan» y menú; identidad de Pachi al centro, no interactiva.

MessageList + MessageBubble

Orden de mensajes. Cada burbuja representa persona, Pachi o espera; la lista anuncia mensajes nuevos con `role="log"` y `aria-live="polite"`.

Composer

Edita y emite el mensaje actual. En D1 no lleva micrófono ni contiene lógica de proveedor.

LocationPrompt

Expone permiso y alternativa de zona; no envía ubicación a API ni al prompt.

UsagePanel

Representa usage completo, parcial o no disponible. No inventa tokens ni costo.

InlineNotice + ConfirmDialog

Muestran error/cuota y confirmación de reinicio; el cliente define acciones y el slice administra el estado.
